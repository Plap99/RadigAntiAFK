<h1 align="center">Radig Anti-AFK</h1>

<p align="center">
  Mod cliente para Minecraft Forge que realiza acciones automáticas configurables para ayudar a evitar que el jugador quede AFK.
</p>

## Características

- Acciones Anti-AFK automáticas y aleatorias.
- Caminar hacia adelante, atrás, izquierda o derecha.
- Saltar y agacharse.
- Giro suave de cámara hacia izquierda o derecha.
- Opción para regresar aproximadamente al punto de origen después de caminar.
- Intervalos de acción configurables.
- Configuración desde una interfaz dentro de Minecraft.
- HUD con estado del Anti-AFK y tiempo aproximado hasta la siguiente acción.
- Configuración persistente entre sesiones.
- Mod completamente del lado del cliente.

## Requisitos

- Minecraft 26.2
- Minecraft Forge 65.1.0 o compatible dentro del rango indicado por el mod
- Java 25

## Instalación

1. Instala Minecraft Forge para Minecraft 26.2.
2. Descarga el archivo `radigantiafk-1.0.0.jar` desde la sección **Releases**.
3. Copia el archivo `.jar` dentro de la carpeta `mods` de tu instalación o perfil de Minecraft.
4. Inicia Minecraft con Forge.

No es necesario instalar el mod en el servidor: Radig Anti-AFK funciona del lado del cliente.

## Controles

- **F8** — Activar / desactivar Anti-AFK de forma predeterminada.
- **F7** — Abrir la configuración de Radig Anti-AFK.

Las teclas pueden reasignarse desde la configuración de controles de Minecraft.

## Configuración

Desde la pantalla de configuración puedes activar o desactivar individualmente las acciones, ajustar los intervalos entre acciones, configurar el rango de giro, modificar la duración de la caminata y decidir si el personaje intentará regresar a su posición anterior después de caminar.

## Uso responsable

Algunos servidores pueden considerar los sistemas Anti-AFK contrarios a sus reglas. Revisa las normas del servidor en el que juegas antes de utilizar el mod. El usuario es responsable del uso que haga de Radig Anti-AFK.
